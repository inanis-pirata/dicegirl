dicegirl 规则书生成器

离线单文件：下载后双击打开即可使用，不联网。产出的 YAML 放进 <数据根>/rulebooks/，在骰子里执行 rule validate 生效。 引擎以 KnownFields(true) 严格校验：多写、错拼任何字段名都会报 CONFIG_INVALID， 本页生成的字段名与内置规则书完全一致，可放心使用。

基本信息

属性（characteristics）

id 是卡上的规范键（建议大写英文）；name 是显示名；aliases 是玩家可输入的别名。别名不得与其他属性的 id/显示名重复。

技能（可选）

键为技能 id（小写英文）；起始值二选一：固定 base 或公式 base_expr（可用属性作变量，如 DEX/2）。

检定机制（mechanic）

成功等级（checks.levels）

按顺序判定，首个命中生效。除最后一档外每档都要写 when（可用变量 roll/target）；最后一档是兜底，when 必须留空。

难度修正（可选）

expr（改写目标，如 target/2）与 auto（命中即指定成功等级）只能二选一。

对抗检定（opposed）

资源轨 vitals（可选）

max/initial 是公式，可用属性与先声明的派生值（如 max_hp）。resource 是轨 id，name/aliases 供玩家按名字使用。

派生值（可选）

整数值公式（可用属性与其前面已声明的派生值），如 max_hp = 体力相关公式。

资源检定（可选，如理智检定）

检定目标是资源现值；成功/失败各掷一条损失表达式。fumble_loss 填 max 表示大失败按最大损失扣。

死亡豁免 death_save（可选，5e 系）

全留默认可只写 death_save: {}；crit 与 critfail 必须不同，成功线不得超过天然大成功值。掷骰使用上方 mechanic 的表达式。

随机表（可选）

每张表：id / 名称 / 骰式（如 1d10）；行格式「范围|文本」，范围如 1-2 或 5。文本中可用 {1d10} 内嵌掷骰。

规则速查（可选）

供 rule ref 词条 查询；每条：id / 标题 / 关键词（逗号分隔）/ 正文。
